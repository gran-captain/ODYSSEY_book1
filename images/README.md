# 📁 Изображения книги "ODYSSEY: ГРАНЬ"

Эта папка содержит все иллюстрации для книги.

## Структура:

- **covers/** — Обложки книги
- **ships/** — Корабли и транспорт
- **crystals/** — Кристаллы и артефакты
- **locations/** — Локации и станции
- **characters/** — Персонажи
- **chapters/** — Иллюстрации для глав

## Стиль:

Все изображения выполнены в едином стиле:
- Жанр: Sci-fi, cyberpunk, gritty realism
- Цветовая палитра: оранжевый (#ff9500), циан (#00d9ff), тёмный космос (#0a0e1a)
- Освещение: Dramatic cinematic lighting

## Промпты:

Все промпты для генерации изображений находятся в файле `image-prompts.md` в корне репозитория.
